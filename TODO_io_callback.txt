Roadmap: jax.experimental.io_callback + jax.effects_barrier
============================================================
Pattern: host I/O and large device→host transfers happen inside (or immediately
after) traced code via io_callback(..., ordered=False), then jax.effects_barrier()
to cap in-flight GPU state (see run_design_grid / multistate pools / STE).

Reference implementations in this repo:
  - prxteinmpnn/run/multistate_pools.py — vmap + lax.map + io_callback
  - prxteinmpnn/sampling/ste_optimize.py — logits save + effects_barrier
  - prxteinmpnn/io/designs.py — DesignArrayRecordWriter + get_io_callback_fn; write() still uses device_get

External reference (streaming / tiling idioms):
  - jaxbeans (if available in sibling checkout) — match io_callback + effects_barrier usage to local patterns.

Multistate ``state_vmap_exact`` logits/scoring (preferred when many states — avoids one huge flat encoder graph):
  - Model: ``score_*_state_vmap_exact`` on ``PrxteinMPNN`` / ``PrxteinLigandMPNN`` (scatter + fuse).
  - Factories: ``make_unconditional_logits_state_vmap_fn``, ``make_conditional_logits_state_vmap_fn``;
    ``make_score_fn(..., multistate_mode="state_vmap_exact")`` (pass stack arrays as keywords).
  - Host stacks: ``prxteinmpnn/sampling/state_vmap_prep.py`` (``build_state_vmap_exact_stacks``, ``slice_flat_tensor_to_stack``).
  - Grid runner: ``scripts/run_unconditional_logits_grid.py --multistate-mode state_vmap_exact`` (LigandMPNN).
