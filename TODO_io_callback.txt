Roadmap: jax.experimental.io_callback + jax.effects_barrier
============================================================
Pattern: host I/O and large device→host transfers happen inside (or immediately
after) traced code via io_callback(..., ordered=False), then jax.effects_barrier().
Policy: **do not use ordered=True** — it forces sequential host sync per callback;
stay on ordered=False and use barriers / bounded sinks for staging.
to cap in-flight GPU state (see run_design_grid / multistate pools / STE).

Reference implementations in this repo:
  - prxteinmpnn/run/multistate_pools.py — vmap + lax.map + io_callback
  - prxteinmpnn/run/sampling.py — ``_sample_batch`` per-chunk scalar marker io_callback + barrier pre-concat (PR1); **structure-batch** scalar marker at tail (PR3a) + **concat-anchor** ``effects_barrier`` before final ``jnp.concatenate`` in non-streaming ``sample()`` / averaged mode; campaign/arrayrecord chunk loops pass ``emit_structure_batch_io`` only on **last** chunk per iterator batch
  - prxteinmpnn/run/scoring.py — ``_score_standard_mode`` / ``_score_streaming`` / ``_score_batch_averaged`` structure-batch scalar marker io_callback + barrier before ``jnp.concatenate`` in ``score()`` (PR2b + **PR2c** averaged)
  - prxteinmpnn/sampling/ste_optimize.py — logits save + effects_barrier
  - prxteinmpnn/io/designs.py — DesignArrayRecordWriter + get_io_callback_fn; ``write()`` uses
    ``device_get`` only for JAX arrays (NumPy payloads skip redundant fetch)

External reference (streaming / tiling idioms):

``_sample_batch`` contract (plan gate / roadmap §14): ``compute_pseudo_perplexity`` runs after ``jnp.concatenate`` of per-chunk logits — JIT-tail chunk streaming must not drop full-sample logits unless perplexity is redesigned (e.g. per-chunk NLL + host combine). ``return_logits`` and HDF5/ArrayRecord callers rely on unchanged concat axes until sinks consume host-side only.

**PR1 slice (2026-05-07, plan-auditor NEEDS_WORK):** ``_sample_batch`` emits a **scalar** chunk-marker ``io_callback(..., ordered=False)`` after each chunked ``vmap_structures`` (host hook ``_noop_sampling_chunk_io``, default no-op) and ``jax.effects_barrier()`` immediately **before** ``jnp.concatenate``. This does **not** stream logits/sequences early; HDF5/ArrayRecord adapters and scoring / jacobian / conformational parity are **explicit follow-ups**.

**PR2c slice (2026-05-09):** ``_score_averaged_mode`` / ``_score_batch_averaged`` emit the same **scalar** structure-batch ``io_callback(..., ordered=False)`` as PR2b, **once per iterator batch** at the **tail** of the averaged forward (after both ``average_encoding_mode`` branches), **not** inside ``score_one``. Per-batch ``effects_barrier`` in the averaged host loop was **removed** for **concat-anchor** parity with standard non-streaming; ``score()`` still barriers immediately **before** ``jnp.concatenate``. Tensor D2H / sink unify still open.

**PR2b slice (2026-05-06):** ``_score_standard_mode`` and ``_score_streaming`` emit a **scalar** structure-batch marker ``io_callback(..., ordered=False)`` after each traced ``vs(...)`` via ``_noop_scoring_structure_batch_io``; ``score()`` calls ``jax.effects_barrier()`` immediately **before** ``jnp.concatenate`` of per-batch lists. Streaming keeps ``effects_barrier()`` **after** each batch **before** HDF5 writes. ``batch_count`` is ``-1`` when the iterator has no ``__len__``. Tensor D2H / sink unify still open.

**PR3a slice (2026-05-06):** Non-streaming ``sample()`` and ``_sample_averaged_mode`` use **concat-anchor only** (single ``jax.effects_barrier()`` before ``jnp.concatenate`` of per-batch lists — removed per-batch barrier after ``_sample_batch``). ``_sample_batch`` gains optional ``emit_structure_batch_io`` (default ``True``); **campaign** HDF5 and ArrayRecord chunk loops set ``emit_structure_batch_io`` only when ``chunk_start + chunk_count >= total_num_samples``. Tail ``io_callback(..., ordered=False)`` to ``_noop_sampling_structure_batch_io``. ``_sample_batch_averaged`` mirrors scoring PR2c markers.
