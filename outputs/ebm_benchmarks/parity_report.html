01The verdict

The port is correct at the tensor level, fast at the systems level, and — once the evaluation harness is corrected — accurate at the science level. Three results establish this:

  • Throughput parity is real and strong. On a fair energy-throughput comparison against PyTorch-eager, the JAX port is 1.5–3.3× faster on Blackwell and 1.8–4.2× on H200, and it completes batch/length cells where the reference PyTorch runs out of memory — on both GPUs, at identical cells, despite the H200's 47% larger VRAM.
  • Accuracy parity is reproduced. The first accuracy runs fell far short of the paper (decoy 0.320, ΔΔG 0.169). Because the ported weights already match reference energies numerically, the gap had to live in the evaluation protocol — and it did. Correcting five harness-side defects (§3) lifts decoy ranking to 0.828 (paper 0.838; best-of-sweep 0.857) and ΔΔG stability to 0.699 (paper 0.686), both at or above the published targets.
  • The model was never wrong. Every fix is in the scoring harness, not the trunk or the weights; the library defaults and all 40 unit tests are unchanged.

Why the numerical check passed while accuracy first failed. The checkpoint-parity gate validates on random aatype integers, which select the same embedding row in both frameworks regardless of whether that row is semantically the right amino acid. A residue-alphabet permutation is therefore invisible to the numerical gate but catastrophic for any real-sequence task — which was exactly the dominant defect. The lasting fix (§4) hardens the gate with a real-sequence assertion.

The natural experiment that pinned the cause. In the first run, ΔΔG ranking — purely sequence-driven — collapsed hardest (0.17), while decoy ranking, which holds the sequence fixed and varies only coordinates, degraded less (0.32). That asymmetry was the fingerprint of a sequence-embedding defect (finding #1), and correcting it recovered ΔΔG the most (0.17 → 0.70). The decoy path, already sequence-correct, recovered from the coordinate-side fixes (#3, #4).

Root-cause findings (code-confirmed; all fixed in commit 0fc1b4ae)

  1. Amino-acid alphabet is permuted critical · both tasks

    The ported sequence_embedding table preserves the reference's AF2 residue order (A R N D C Q E G H I L K M F P S T W Y V), but the harness feeds MPNN-ordered indices (A C D E F G H I K L M N P Q R S T V W Y) with no conversion. The two orders agree on only 4 of 20 residues, so 16/20 residue types look up the wrong embedding row.

    Confirmed: aa_convert.py:16–17 (the two orders) · ddg_stability.py:206 (MPNN indexing) · model.py:187 (direct lookup, no mpnn_to_af). Invisible to the numerical gate, which uses random integers. This alone explains why ΔΔG (pure sequence) collapses and decoy (fixed sequence) merely degrades.

  2. ΔΔG unfolded-state correction is a mathematical no-op major · ΔΔG

    The reference scores the unfolded ensemble with each mutant sequence, so the folded-vs-unfolded gap varies per mutant and carries real ΔG-of-folding signal. The harness computes the correction from the wildtype sequence — a single constant across all mutants. Subtracting a constant cannot change rank order, so the entire correction contributes zero to the Spearman.

    Confirmed: real_ddg_stability_benchmark.py:139–143 passes wildtype.aatype. The score collapses to E(wt-backbone, mutant-seq) alone.

  3. Coordinates are not centered major · decoy + ΔΔG

    The reference applies center_random_augmentation to every scored structure. The model is not translation-equivariant, so absolute position matters. The harness only scales coordinates (×0.1) and never removes the centroid, and the folded/unfolded ΔΔG pair ends up in inconsistent frames.

    Confirmed: real_decoy_ranking_benchmark.py:152, ddg_stability.py:218.

  4. Wrong contact / self-conditioning defaults minor

    The checkpoint was trained with external_contacts = ones and (for ΔΔG) self-conditioning on the folded template. The harness passes None for both, which defaults to zeros — selecting the wrong contact-embedding row and disabling self-conditioning.

    Confirmed: model.py:342–345. Decoy self-conditioning happens to match the reference default (zeros); the contact default does not.

  5. Noise-time evaluation point minor

    The harness pins t=0.05 as the pre-registered comparison; the reference reports nearer its per-target peak (t≈0.10) or best-of-sweep. A real but secondary contributor: the decoy best-of-sweep |ρ| is 0.48 — half again the pinned-t 0.32 — so ~0.16 of the decoy gap is recoverable from the evaluation point alone.

04Fixes applied

All defects were in the evaluation harness and scoring-call path, not the trunk or the weights — low-risk and independently testable. Five corrections, all in commit 0fc1b4ae, took the numbers from the initial column to parity:

  • AF2-ordered aatype (dominant). The ΔΔG harness now builds sequences with sequence_to_af_aatype instead of the MPNN-ordered string_to_protein_sequence, so the embedding lookup hits the row the checkpoint was trained on. (The decoy path was already AF-correct via parse_structure.)
  • Reference ΔΔG estimator. The unfolded correction — previously a wildtype constant, i.e. a no-op on rank order — now scores the folded template and each unfolded member with the mutant sequence: score = −E_fold + meanu E_unf, ddg = score_wt − score_mut.
  • Coordinate centering (both paths): subtract the CA centroid before scoring, since the model is not translation-equivariant.
  • external_contacts = ones (both paths): the checkpoint has num_contact_embeddings == 3, so the reference defaults contacts to ones, not zeros. Threaded through score_decoy_batch / sweep_noise_time_energies / rank_decoys_over_noise_time as a backward-compatible optional argument.
  • ΔΔG self-conditioning set to the folded template (was zeros).

Still open: harden the numerical gate with a real-sequence parity assertion (not just random integers) so an alphabet permutation can never pass silently again.

05Methodology & provenance

  • Throughput — batch-swept decoy_benchmark / ddg_benchmark runs, 10 repeats/cell, bf16, real 85M checkpoint. Blackwell & H200 result JSONs consolidated by scripts/ebm/summarize_throughput_parity.py → throughput_parity_corrected.json.
  • Accuracy — scripts/ebm/real_decoy_ranking_benchmark.py (Rosetta decoy set + TM-score labels) and real_ddg_stability_benchmark.py (Tsuboyama-2023 + AF2 structures), scored against the orbax-ported checkpoint on GPU with the corrected protocol. Both write per-target results incrementally; corrected results are the *_fixed_full.json outputs (133 natives / 64 assays, uncapped).
  • Numerical parity — scripts/ebm/checkpoint_parity_check.py (energies match the reference to tolerance; masked residues contribute exactly zero on both sides). The harness fixes touch no model or checkpoint code, so this gate is unaffected; the 40 test_decoy_ranking / test_ddg_stability unit tests still pass.
  • Root cause — harness scoring path compared line-by-line against the reference ProteinEBM repo (score_decoys.py, ddg_prediction.ipynb, protein_utils.py) and the design spec's stated targets.
