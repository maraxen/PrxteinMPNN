ProtonPottsMPNN · runs entirely in your browser

Protonation-aware ProteinMPNN variant of the aminx port. Inference uses onnxruntime-web (wasm), with no server round-trip. Only the methods validated in the browser are offered: scoring, pH block-descent design and sequence sampling.

Structure

Comma-separated, one entry per residue the parser loads, in file order. An empty entry means no label.

1. Score variants

One variant per line: name: tokens or just tokens. Tokens are separated by commas or spaces. Without separators, each character is one residue. Tokens are one-letter codes or protonation tokens (HIS-P, HIS-S, HIS-A, ASP-P, ASP-D, ASP-A, GLU-P, GLU-D, GLU-A). Each row must have one token per kept residue. The native sequence is always row 0.
